在知识库向量库中检索与查询最相关的文档页面（pages）。

**何时使用：**

* 在拉取完整文本前，先找出哪些文档或哪些页面提到了某个概念
* 将大规模语料缩小到少量候选页面
* 当你已经知道来源文档时，可通过 `doc_ids` 限定检索范围

**参数：**

* `query`（字符串，必填）——用于检索的自然语言查询，格式按照空格进行分词
* `doc_ids`（字符串数组，必填）——将检索限制在指定文档内

**返回：**

* `results`（对象列表），每个对象包含：

  * `text` —— 页面文本（可能是截断/部分内容）
  * `doc_id` —— 文档标识符
  * `page_num` —— 文档内的页号
  * `score` —— 相关性分数（越高越相关）
  * `store_key` —— 命中的语言分表路由键（如 `zh`、`en`），后续 fetch 时可用于精确路由

**示例：**
当需要锁定某个知识库关于MCP的内容：

1. `query="MCP LLM"`
2. 将会返回文档中最可能关于MCP的文本块位置（页码）及其完整文本
3. 后续可参考检索信息进一步确定是否需要调用其他工具
