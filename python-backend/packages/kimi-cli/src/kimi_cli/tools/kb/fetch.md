获取指定 `doc_id` 与对应分块的完整文本内容。

**何时使用：**

* 在完成一次检索后，如果尚不能清楚确认已经拿到用户所需信息的“完整内容”，建议用该工具拉取相邻的若干 `page_num`，以确保获取到知识库中完整上下文。
* 当你已经明确知道需要的 `doc_id` 和 `page_num` 时。

**参数：**

* `doc_ids`（字符串列表，必填）——要从中获取内容的文档标识符
* `page_nums`（整数列表，必填）——要检索的文档页号，一次查询不要超过五个（请勿重复查询已获取到文档内容）

**返回：**

* `results`（对象列表），每个对象包含：

  * `text` —— 该分块的完整文本
  * `doc_id` —— 文档标识符
  * `page_num` —— 文档内的页号
  * `store_key` —— 若命中唯一语言分表，则返回对应路由键

**示例：**
从同一篇文档中获取两个分块：
`doc_ids=["doc-123"]`, `page_nums=[4, 5]`
