# 当前目录职责：存放 Java backend 压测脚本与该目录下的维护约束。

## 范围

- 仅放置面向 `backend/learyAI` 的压测脚本与配套说明。
- 当前统一使用 `k6`，不再新增 `jmeter`、`wrk`、`hey` 等其他格式脚本。

## 脚本约束

- 一个脚本只覆盖一条清晰链路或一个明确接口。
- 脚本文件名应直接体现目标，例如 `recent-visits.k6.js`。
- 脚本顶部必须使用注释说明职责。
- 默认参数通过环境变量注入，不要把真实域名、真实 cookie、真实账号写死在脚本中。

## 验证重点

- 优先覆盖首页高频、核心依赖、容易回归的接口。
- 输出应能直接观察状态码、延迟分位、失败率。
- 涉及鉴权接口时，只约定 header/cookie 结构，不提交真实凭据。
